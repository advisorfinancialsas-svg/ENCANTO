# Encanto Confecciones MC — sitio web

Sitio corporativo construido con Next.js 16.4.6, React 19.3.1 y TypeScript.

## Requisitos
- Node.js 20.9 o superior (recomendado Node 22 LTS)
- npm

## Desarrollo local
```bash
npm install
npm run dev
```
Abre http://localhost:3000.

## Compilar para producción
```bash
npm run build
npm run start
```

## Despliegue en GitHub y Vercel
1. Crea un repositorio nuevo en GitHub, por ejemplo `encanto-confecciones-mc`.
2. Desde esta carpeta abre la terminal y ejecuta `git init`, `git add .`, `git commit -m "Primera versión Encanto Confecciones MC"`, `git branch -M main`, `git remote add origin https://github.com/TU-USUARIO/encanto-confecciones-mc.git` y `git push -u origin main`. Reemplaza `TU-USUARIO` por tu usuario de GitHub.
3. En Vercel, importa el repositorio desde **Add New → Project**.
4. Framework Preset: Next.js. Build Command: `npm run build`. Install Command: `npm install`.
5. Despliega. Cuando esté listo, configura el dominio `encantoconfeccionesmc.com` en Settings → Domains si el dominio está bajo tu administración.
